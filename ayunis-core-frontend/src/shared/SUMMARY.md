# Shared Application Infrastructure

Application-wide infrastructure, generated API client, utilities, and app-aware shared UI.

The shared layer provides application-aware shared components, an Orval-generated TypeScript API client with TanStack Query hooks (~13,600 lines), Axios HTTP client configuration, i18n locale files for German and English, chat context provider, error boundary components, and utility libraries. Application-independent design-system primitives and theme tokens live in the `@ayunis/ui` workspace package under `packages/ui`.

The `api/` directory contains the Orval-generated client in `generated/ayunisCoreAPI.ts` (~10,700 lines of typed React Query hooks for every backend endpoint, including artifact and letterhead CRUD/export flows) and `generated/ayunisCoreAPI.schemas.ts` (~2,900 lines of TypeScript interfaces matching backend DTOs). The `client.ts` file configures the shared Axios instance with base URL and authentication interceptors, while `extract-error-data.ts` provides error response parsing and exports the `FieldError` interface for structured validation errors (with `field` and `constraints` properties) and includes an optional `errors` array in the returned `ErrorData`. `me-query-options.ts` exports `meQueryOptions`, the shared `/auth/me` query definition both route guards read, so the authenticated layout and the login route resolve the session from one cache entry. The `ui/error-boundary/` provides React error boundary with fallback UI. The `ui/help-link/` provides a HelpLink component for linking to external help center documentation with icon and default variants. The `contexts/chat/` implements a chat context provider for sharing conversation state across components. The `hooks/` directory includes a `useDragOver` hook that tracks drag-over state on a container element and delivers the raw `FileList` on drop, a `useDocumentDrop` hook that builds on `useDragOver` to add file-type validation for document uploads, a `useDebouncedValue` hook that returns a copy of a value which only updates after it has stayed unchanged for a given delay (used to throttle search-driven network requests), and `useDropdownDialogTransition`, which opens a dialog from a dropdown's close-autofocus event so focus is transferred without timing hacks. The `locales/` directory contains German and English translation JSON files organized by feature area, including dedicated namespaces for artifact editor copy and admin letterhead settings. The `constants/` directory holds shared constant modules: `department.ts` defines the selectable department keys (the frontend owns this list; the backend accepts any string) and exports `DEPARTMENT_KEYS`, `DepartmentKey`, and `DEPARTMENT_OTHER_MAX_LENGTH`; `secret-mask.ts` provides secret masking utilities. The `lib/` directory provides DOM patch utilities, a `help-center.ts` utility for building locale-aware help center URLs, a `computeUsagePercent` helper for calculating clamped percentage values, `compute-department.ts` which exports `computeDepartment` (resolves department + free-text "other" into the `other:<text>` wire format) and `refineDepartmentOther` (shared Zod superRefine callback for the other-text required check), `set-validation-errors.ts` which exports `setValidationErrors` for mapping backend `FieldError` arrays to react-hook-form field errors with i18n-aware message resolution, and `password-policy.ts` which exports `isValidPasswordPolicy` (validates the backend-enforced policy: ≥8 characters with at least one uppercase letter, one lowercase letter, and one digit) and `passwordPolicySchema` (Zod schema factory for password fields with a single configurable message), and `safe-redirect-path.ts` which exports `safeRedirectPath` (constrains the attacker-reachable `?redirect` param to a single-slash in-app path, falling back to `/chat`, and is applied by every post-authentication navigation). The `ui/department-field/` directory provides a reusable `DepartmentField` form component (select dropdown with conditional free-text input for "other"). The `ui/provider-flag/` directory provides the `ProviderFlag` component, which renders a model provider's hosting-region flag (DE/EU/US) as an inline SVG so flags display consistently across browsers, including Microsoft Edge on Windows where Unicode flag emoji have no glyphs. The `config/` directory exports environment-based application configuration. The `assets/brand/` directory contains branding resources. `lib/use-reset-form-on-open.ts` exports `useResetFormOnOpen`, which re-seeds a react-hook-form instance when a kept-mounted dialog transitions to open (dialog forms would otherwise reopen showing a stale draft). `lib/move-by-id.ts` is the shared array-reorder helper behind every dnd-kit sortable list. `lib/workspace-appearance.ts` holds the workspace icon catalogue (64 administration-themed lucide icons keyed by short string, which is what the backend stores), the six-colour palette, and the helpers around them (`resolveWorkspaceIconKey`, `isCustomWorkspaceColor`, `isLightColor`, `defaultWorkspaceColor`); `ui/workspace-icon/` renders a workspace's icon in its colour, mixing user-picked hex values per theme via `color-mix` so an arbitrary colour stays readable in light and dark mode.
